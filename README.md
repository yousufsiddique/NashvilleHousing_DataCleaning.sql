# Nashville Housing Data Cleaning

## Overview
Cleaned and transformed the Nashville Housing dataset using SQL Server.

## SQL Skills Used
- Joins
- CTEs
- ROW_NUMBER()
- Window Functions
- Data Cleaning
- String Functions
- ALTER TABLE

## Cleaning Tasks
- Standardized date formats
- Populated missing property addresses
- Split address columns
- Converted Y/N values to Yes/No
- Removed duplicates
- Dropped unused columns

## Tools
- SQL Server
- SSMS
